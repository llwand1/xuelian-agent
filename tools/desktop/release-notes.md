StudentBuddy Windows 0.2.211 · Windows 10/11 x64

应用内版本 0.2.189，桌面发行版本 0.2.211。

- 本机外置 Agent 文本对话：统一设置与配对，提供 Codex、OpenCode、Qoder 参考桥下载；历史保存在 StudentBuddy，支持停止、重试与编辑重发。
- Qoder CN 已验证真实多轮问答、历史续接与取消；需要本人完成官方 CLI 登录。各家账号、额度与模型可用性独立，不自动改用其他服务商。
- 学习工作台首页更新中英文文案与交互演示，明确共读、图解、练习、复习和桌面专属能力。
- 引用分支保留来源锚点，独立追问不改主线；HTML 卡片支持语法检查、诊断、静态查看和点击修复。
- 知识矿境采用角落状态、固定施法键及短题卡，优化移动与动作反馈，已有词库、学习记录与偏好保留。

安装与升级：下载安装程序；已有自动更新版可从托盘检查更新，校验后选择重启更新。保留数据、配置、应用名及更新签名。早期版本需手动安装一次新版。

外置 Agent 默认关闭，仅允许本机回环连接；第三方登录凭据由各自 CLI 管理。桥接只提供文本回复，不授予任意文件、终端或桌面控制权限。

本 Release 同时提供浏览器共读扩展、SHA-256 校验文件和签名更新清单。发布前执行安装、跨版本升级及签名自动更新隔离验证。安装程序本身尚未做 Windows 代码签名。
