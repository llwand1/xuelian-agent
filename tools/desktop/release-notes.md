StudentBuddy Windows 0.2.208 · Windows 10/11 x64

本次汇入 0.2.201 之后的桌面学习更新，应用内版本为 0.2.187，桌面发行版本为 0.2.208。

- 安静学习来信：备题完成只用吉祥物动作提示，不自动弹窗。从悬浮球悬停菜单主动打开「学习来信」，可关闭后重新查看；番茄钟分别设置出题间隔和延后时间，均为 1–60 分钟，定时练习仍默认关闭。
- 知识矿境与动作轮播：横版探索与常规刷词共用题目、判分和复习记录。刷怪、动作轮和怪物攻击间隔可调，可编排平 A / 防御；答对与答错分别结算命中/闪避、护盾/防御失败。「斩」只跳过动作，不计作掌握。答题时世界继续，主动休整才暂停。
- 每日学习任务：设置个人题量目标、进度、提醒时段和时区，正式题卡与常规/游戏刷词共用事件记录，重复提交不会重复计数。
- 引路灯与视频：悬浮球可按本人设置提示已有学习建议；视频支持关闭、页内悬浮/放大/还原及当前实际画面截图，预览后保存或附到输入框，不自动发送。
- 设置与插件：独立导航分区、可删除服务商的权限及绑定修复、统一插件 v2、TinyFish 官方 MCP 接入和桌面本地 Agent 参考桥。桥接须显式配对，只共享指定资料，不自动读取全部词库、会话或控制任意已安装 Agent。

安装与升级：下载 Assets 中的安装程序；已有自动更新版可从托盘检查更新，校验完成后选择重启更新。应用名、既有数据目录与更新签名保持不变，升级和卸载保留学习数据。0.2.0 及更早版需手动安装一次新版。

本次保留 B站真实资料学习、网页共读、逐题思考/解析、后台任务与本机截图能力。第三方视频限制不由应用绕过；Agent 演进与联机权威内核仍是独立模块，正式主程序未交付公网大厅或账号联机。

本 Release 同时提供浏览器共读扩展 ZIP、SHA-256 校验文件与签名自动更新清单。安装、跨版本升级及签名自动更新使用隔离环境验证，不在个人安装上执行测试。安装程序本身尚未做 Windows 代码签名。
