StudentBuddy Windows 0.2.210 · Windows 10/11 x64

应用内版本 0.2.188，桌面发行版本 0.2.210。

- 对话内联 HTML 卡片：自包含动画、Canvas 模拟器和交互小工具就在消息里运行，不上传预览、不新开浏览器窗口。
- 支持停止、重播、展开、查看源码与复制。整轮回复完成才运行；历史点击启动；隐藏或离屏后停止，不自动恢复内部状态。
- 独立沙箱不获宿主会话数据与本机权限，限制外部资源、内容大小和同时运行数量；不放宽桌面原生消息来源检查。
- 手动展开、源码和重播时退出贴底跟随，操作栏保持可达，展开不重载当前卡片。

安装与升级：下载 Assets 中安装程序；已有自动更新版可从托盘检查更新，校验后选择重启更新。保留学习数据、配置、应用名和更新签名。0.2.0 及更早版需手动安装一次新版。

本次仅发布 HTML 卡片，不包含本机未发布的 0.2.209 矿境手感改动。现有正式版的知识矿境、学习来信、网页共读和视频能力保留。

本 Release 提供浏览器共读扩展 ZIP、SHA-256 与签名自动更新清单。安装及升级使用隔离环境验证，安装程序本身尚未做 Windows 代码签名。
