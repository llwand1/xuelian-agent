# 设置分区与插件标准 v2 — 2026-10-15

## 本批实现

- SettingsView 改为七个独立分区：模型与服务商、学习与出题、联网搜索、阅读与交互、插件中心、外部 Agent 授权、工具与诊断。只挂载当前页；导航保留，窄屏横向导航，内容独立滚动。模型 CRUD 提取 ModelSettings。
- 删除根因：前端 `ownerId === null` 被当成不可删，但本机新增 provider 也为 NULL；改由服务端返回 editable/deletable。系统种子明确不可删除，避免 seedIfEmpty 删除后原样补回；平台行对登录用户仍不可改。确认/取消、请求中状态、错误反馈；事务重绑并清空旧模型，归属仍限制当前用户。
- 插件统一 schemaVersion=2：publisher、kind、network、auth、逐工具 permissions；v1 后向兼容。内置身份不可覆盖；权限标签不等于信任，也不绕过逐次许可。
- TinyFish 固定官方远程 MCP + X-API-Key；有限工具白名单、异步网页自动化 + 查询/取消；不提供假 OAuth 或默认凭据。
- 桌面限定本地 Agent MCP，字面回环 IP、显式端口、独立 Bearer 密钥、Origin/Host/peer/启动标记保护；公网 MCP 的 SSRF 边界不放宽。没有任意命令/stdio 导入能力。
- 零依赖可运行参考桥 + 可选本地兼容 API worker：双向共享箱、任务幂等、领取/结果归属、真实结果查询、持久化、数据清理。桥接器本身不是 Agent，不自动操纵已安装的程序。

完整规范与运行方法的唯一维护源：`packages/web/public/plugin-development.md`，随 Web/桌面构建分发。
JSON Schema：`packages/web/public/plugin-manifest-v2.schema.json`。

## 桌面实装追补（2026-10-20）

- 现场根因：快捷方式启动的是已安装的桌面 0.2.201；前一批 0.2.202 只打包未安装，所以用户实际仍是旧长页，NULL 归属的本机自建服务商仍被误判只读。修复代码不能代替实际客户端交付。
- 设置改为七分类、十六个独立叶子页。模型分类拆成供应商管理、角色模型绑定、默认通道与额度；学习、交互、诊断也按单项拆页。仅挂载当前叶子，按页请求数据；切换重置滚动，记住分类内上次子页和本次会话的最后位置。窄屏使用分类下拉与子页导航，不把所有设置堆成长页。
- 供应商从宽表格改为响应式卡片，删除入口始终位于卡片内，确认/取消、请求中禁用、失败原位反馈保留。自建 NULL 归属行按服务端 editable/deletable 权限可删；系统默认通道保留。删除事务重绑并清空旧模型名，不扩大托管模式下的平台权限。
- 默认配置提示不再写死八个角色，避免与当前服务端十角色矛盾；成功提示和探针按服务端角色数量验证。
- 全量 467 文件、4918 用例：4915 通过、3 跳过、0 失败；TypeScript/ESLint、Web/Server 构建及工程门禁通过。
- 生产资源与桌面打包目录分别跑真实浏览器探针，均 48/48 通过；覆盖全部叶子导航、真实删除/取消/绑定回落/默认保护、390px 与 320px 无横向溢出且删除可见。测试使用隔离数据库和假模型列表，不调用真实模型。
