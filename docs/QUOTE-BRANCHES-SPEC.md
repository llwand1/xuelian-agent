# 对话内隐藏追问分支

2026-10-25。本机专项，替代对话页「选中文字→把引用拼进主输入框」的旧交互。

## 行为

- 在已保存的助手正文中选中一个字、术语或一段文字（最多 1200 字），点击「小窗追问」打开非模态浮窗；主输入框及草稿不变，也不会自动发起模型调用。
- 输入追问后发送；留空点击「解释这段」才提交默认解释请求。回答和后续提问都在小窗内，不进入主消息流。
- 对话正文中现有词条卡的追问也使用此分支；非对话来源的词条库追问保留原有入口。分支窗口中的词条卡不再提供会跳回普通会话的旧追问动作。
- 原文字段以特殊高亮/点状下划线标记，点击恢复同一分支；辅助的小型标记按钮支持键盘和不支持 Custom Highlight API 的环境。相同文字在不同消息或不同位置分别建分支，同一精确锚点复用分支。
- 小窗可拖动、桌面可调整尺寸，窄屏自动适配。关闭/按 Escape 只收起，保存历史；关闭不终止已提交的生成。刷新或断线后重开可恢复已存内容和继续查询生成状态，停止按钮仅中止本分支。

## 数据与隔离

- v65 新增 `quote_branch` / `quote_branch_message`，不向 `sessions` / `messages` 插入支线，不更改主会话更新时间；普通会话列表、全文搜索、导出、主线摘要和后续主回答上下文不读取分支表。
- 首次发送时创建分支，保存主会话 ID、原回答 ID、原文、UTF-16 起止偏移和前后文。只读来源快照仅包含原回答及其之前最多 12 条主线消息；不含未来主线回复或别的分支。
- 仅接受已保存、非工具调用的助手回答；归属继承主会话，每个读取/写入/停止端点都校验父会话存在、未删除及访问权。原回答被真正删除（例如重新生成）时外键级联删除对应分支；父会话软删后分支不可访问。
- 独立 `chat.quote-branch` AI 用途，沿用用户的对话模型和网关计量/超时/取消；不调用主 `handleMessage`、主 SSE、工具循环或回复后记忆提炼。分支无联网和工具权限，Markdown 中 HTML 默认不执行。
- 同一分支一次只允许一轮回答，最多 4 个同归属的在途分支；问题最多 4000 字。模型上下文有预算并优先保留当前问题和引用。传输使用独立 NDJSON，不复用主对话消息频道。
- 流式部分按节流落库，终态保存完整文本及 complete/stopped/error；进程重启遗留的 streaming 行在重开时明确标为中断，不伪装成功。断开传输不撤销已提交的回答。

## 定位与验证

使用稳定消息 ID（历史行和 done 帧同源）与文本选择器定位，原偏移必须同时符合上下文，否则按引用前后文重新定位；不对 React 管理的文本节点作 DOM 包装/替换。Custom Highlight API 不改变底层 DOM，参见 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Custom_Highlight_API)。

专项覆盖存储/路由隔离、迁移重放、停止/失败/恢复、重复词及跨格式锚点、前端切会话竞态、原有主聊天回归。`tools/probes/quote-branches-cdp.mjs` 以临时数据库、本机确定性假模型走真实 send/SSE/落库/刷新和桌面/390px 界面；不向个人配置的真实模型发送测试问题。
