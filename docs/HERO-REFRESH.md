# 学习工作台 Hero 更新（2026-10-27）

- 用可交互的示例演示段落追问、浮力图解、练习作答与思考、等待时翻词卡。明确标注无 AI 调用、不写学习记录。
- 横版知识矿境代替旧俯视大陆叙事；示意可移动、答题施法，不伪装成用户存档。
- 补充桌面悬浮球、截图预览、网页/视频共读、任务中心、本机工作区及外置 Agent。
- 外置 Agent 展示同步加入 Qoder，与 Codex、OpenCode 一起标明为独立本机文字接入。
- 区分线上、Windows、本机新功能/独立文字试用；可编辑世界/多人共学仍标原型。移除把旧异火/副本/Boss 叙事当主推功能的章节，历史影像折叠保留。
- 中英文、页面 title/description/OG 文案同步更新；首页分享卡从现有 HTML 生成器重新截图为 1200×630 PNG，不再使用旧大陆文案。品牌副标仍与应用侧栏共用唯一常量。

## 入口与边界

`#/welcome` 是主动查看门面的预览路由；默认入口、登录判断、对战邀请优先级不变。本机 surface 的主 CTA 进入本机应用，不索取云端邮箱；云端仍走原有登录/注册，不绕过认证。

本任务试用地址：`http://127.0.0.1:18991/#/welcome`。未部署公网、未替换已安装桌面程序、未变更个人数据库。
